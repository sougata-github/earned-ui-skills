## What is a bento grid?

A bento grid is a layout of tiles of different sizes packed into one block, named after the compartments of a Japanese lunch box. Each tile holds one idea. It is the common way to show the features of a product in one view.

## Why do AI built bento grids look generic?

Because the tiles are decoration. An agent with no guidance fills rounded boxes with charts and icons that would look at home on any site, so the grid says nothing about the product.

The skill's one rule is that a tile is evidence. Every tile proves one thing the page already says, in the form that thing already has. A conversation is a chat. A schedule is a calendar. A rollout is a slider. A trend is a line.

| A generic bento | A bento built with the skill |
| --- | --- |
| Random charts in every tile | Mostly product UI, a chart only when the data is a series |
| Unrelated sample content | One story and one cast across every tile |
| Looping decoration | Widgets that change state on a beat |
| One layout, shrunk on small screens | An arrangement per screen shape |

## How does the skill work?

widget-bento-web is a workflow your agent follows. Ask for a bento, for example "a features section with live widgets for this product", and the agent reads your page, lists its claims, and picks one story to run through every tile.

Then it builds a lab. You first see the empty bento, each tile a labelled box with a size, and approve the structure before any content exists. After that each widget is built at its real size and shown in the lab in both themes. You click a tile to step through its states, then send changes back or keep the look.

## How do the widgets come alive?

They change state. A button goes from Send to Sending to Sent. A rollout moves from 25 to 50 to 100 percent. A number rolls to its next value. Each widget has two to four states, and one conductor steps two tiles every half second in a fixed order.

Nothing loops for decoration and nothing is random, so the wall looks the same on every load and can be reviewed.

## How do you make a bento grid responsive?

By rearranging the tiles, not squeezing them. A tile has a fixed height and its content is laid out to fill it on whole pixels. A different screen gets the same tiles in a different number of columns, and each arrangement is laid out by hand so every column ends level.

The wall then picks the arrangement for the window. Where one matches the window's shape it fits one screen. Where none does, the wall fills the width and scrolls.

## What is in the skill?

- **A wall engine** in one React file: arrangements per screen shape, a check that every column ends level, the fit to any window, the conductor, and an opening where the tiles land like a home screen on unlock.
- **Two pieces every live widget needs**: a number that rolls to its value and text that crossfades to its value.
- **A lab**: sliders for the structure, empty tiles, click a tile to step it, Copy as JSON.
- **The forms a tile can take**, with when to use each and when not to.
- **Forty lessons**: what looked wrong on screen, why, and what fixed it.

## When is this not the right tool?

When you need a real dashboard. The skill builds a marketing surface, a wall that shows what a product does, on fixed sample data. It is not a charting or data grid library.

It is also for websites. It does not build native home screen widgets for iOS or Android.
